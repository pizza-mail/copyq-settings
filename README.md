📂 Where to drop the file:

Windows: 
%APPDATA%\copyq

Mac: 
~/.config/copyq

Linux:
~/.config/copyq

Linux (Flatpak): 
~/.var/app/com.github.hluk.copyq/config/copyq



&nbsp;

⚠️ Steps:

1) Install CopyQ & Close it.

2) Drop copyq.conf in the path above.

3) Open CopyQ & fix Hotkeys. ( Screenshot hotkey + Show tray hotkey )
